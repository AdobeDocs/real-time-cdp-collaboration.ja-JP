# 重複の数と割合の計算

Adobe Real-Time CDP Collaborationでは、オーディエンスの重複を把握することは、マーケティング戦略を最適化し、広告主とパブリッシャーの効果的な連携を確保するために不可欠です。 このドキュメントでは、サンプルデータを使用して、様々な製品領域の重複カウントと割合を計算する方法について説明します。

## サンプルデータ - ID数

### 計算目的の前提条件

この例では、次の点を想定してください。

* 広告主は3つのオーディエンス（A1、A2、A3）を持つ。
* 発行者には3つのオーディエンス（P1、P2、P3）があります。
* 一致するすべてのキーIDは、すべてのオーディエンスで相互排他的です。

>[!NOTE]
>
>実際には、各オーディエンスの一致する主要ID間に重複が生じますが、単純に言うと、この例では各オーディエンスが排他的であると仮定しています。

### 広告主オーディエンス

| 広告主オーディエンス | A1 | A2 | A3 | すべて |
|----------------------|------|------|------|------|
| ハッシュ化されたメール ID | 300K | 450K | 250K | 1M |
| Liveramp ID ID | 500K | 200K | 700K | 140万 |
| 合計ID数 | 800K | 650K | 950K | 240万 |

### 発行者オーディエンス

| 発行者オーディエンス | P1 | P2 | P3 | すべて |
|---------------------|------|------|------|------|
| ハッシュ化されたメール ID | 150K | 600K | 550K | 130万 |
| Liveramp ID ID | 400K | 350K | 100,000 | 850K |
| 合計ID数 | 550K | 950K | 800K | 230万 |

## 重複カウントと割合の計算

### サンプルデータ – オーバーラップ数

#### 広告主様とパブリッシャー様それぞれ

|---------------------|---------|---------|---------|
| ハッシュ化されたメールによる重複 | 100,000 | 300K | 150K |
| Liveramp Idによる重複 | 200K | 150K | 50K |
| 合計重複 | 300K | 450K | 200K |

## Discover Module

Adobe Real-Time CDP Collaborationの&#x200B;**[!UICONTROL Discover]** モジュールは、オーディエンスデータに関する貴重なインサイトを提供します。 オーディエンスの重複を把握することで、メディア企業と広告主の間の潜在的なコラボレーション機会を特定することができます。 **[!UICONTROL もっと知る]** モジュール内の&#x200B;**[!UICONTROL オーディエンスインサイト]** セクションは、異なるオーディエンス間の重複カウントと割合を分析するのに役立ちます。

![&#x200B; コラボレーションワークフローの検出モジュール。](/help/assets/reference/overlap-calculations/discover-module-overlap-calculations.png)

様々な重複シナリオのサンプル計算と式を以下に示します。

### あらゆる広告主のオーディエンスとメディア企業のオーディエンス

| 広告主オーディエンス | 発行者オーディエンス | ID数（A） | 重複するID （B） | オーバーラップ率 | 一致キーの分類 | 一致キーの分類% |
|----------------------|---------------------|--------------------|----------------------------|-----------------|---------------------|-----------------------|
| すべて | すべて | すべての広告主オーディエンスの合計ID数<br> ID数= 1M + 1.4M = 2.4M | すべての照合キー<br>の重複ID = 1.58Mに対する、すべての広告主オーディエンスとすべての発行者オーディエンスの合計重複 | すべての広告主オーディエンスの合計ID数に対する重複IDの割合<br>重複% = （B / A） x 100 = （1.58M / 2.4M） x 100 = 65.83% <br>重複パーセント = 65.83% | 一致キーごとの重複ID <br> ハッシュ化された電子メールによる重複= 850K <br> Liveramp Idによる重複= 730K | 重複するIDの合計に対する一致キーの重複の割合<br> ハッシュ化された電子メールの一致キー% = （850K / 1.58M） x 100 = 53.8% <br> Liveramp Id = （730K / 1.58M） x 100 = 46.2% |

### あらゆる広告主オーディエンスとメディア企業のオーディエンス

| 広告主オーディエンス | 発行者オーディエンス | ID数（A） | 重複するID （B） | オーバーラップ率 | 一致キーの分類 | 一致キーの分類% |
|----------------------|---------------------|--------------------|----------------------------|-----------------|---------------------|-----------------------|
| すべて | 1 P2 | すべての広告主オーディエンスの合計ID数<br> ID数= 1M + 1.4M = 2.4M | すべての照合キー<br>の、すべての広告主オーディエンスと選択された発行者オーディエンス P2の間の重複の合計重複ID = 860K | すべての広告主オーディエンスの合計ID数に対する重複IDの割合<br>重複% = （B / A） x 100 = （860K / 2.4M） x 100 = 35.83% <br>重複パーセント = 35.83% | 一致キーごとの重複ID <br> ハッシュ化された電子メールによる重複= 530K <br> Liveramp Idによる重複= 330K | 重複するIDの合計に対する一致キーの重複の割合<br> ハッシュ化された電子メールの一致キー% = （530K / 860K） x 100 = Liveramp Id = （330K / 860K） x 100 = 38.38% <br> |

### 1つの広告主オーディエンスとすべての媒体企業オーディエンス

| 広告主オーディエンス | 発行者オーディエンス | ID数（A） | 重複するID （B） | オーバーラップ率 | 一致キーの分類 | 一致キーの分類% |
|----------------------|---------------------|--------------------|----------------------------|-----------------|---------------------|-----------------------|
| 1 A1 | すべて | 広告主が選択したオーディエンスの合計ID数A1 <br> ID数= 300K + 500K = 800K | すべての一致キー<br>の広告主オーディエンス A1とすべてのパブリッシャーオーディエンスの重複の合計数は、重複ID = 600Kです | 広告主が選択したオーディエンスのID数に対する重複IDの割合（A1） <br>重複% = （B / A） x 100 = （600K / 800K） x 100 = 75% <br>重複パーセント = 75% | 一致キーごとの重複ID <br> ハッシュ化された電子メールによる重複= 250K <br> Liveramp Idによる重複= 350K | 重複するIDの合計に対する一致キーの重複の割合<br> ハッシュ化された電子メールの一致キー% = （250K / 600K） x 100 = Liveramp Id = （350K / 600K） x 100 = 58.33% <br> |

### 1つの広告主オーディエンスと1つの媒体企業オーディエンス

| 広告主オーディエンス | 発行者オーディエンス | ID数（A） | 重複するID （B） | オーバーラップ率 | 一致キーの分類 | 一致キーの分類% |
|----------------------|---------------------|--------------------|----------------------------|-----------------|---------------------|-----------------------|
| 1 A2 | 1 P2 | 広告主が選択したオーディエンスの合計ID数A2 <br> ID数= 450K + 200K = 650K | すべての一致キー<br>の選択された広告主オーディエンス A2と選択された発行者オーディエンス P2の重複の合計重複ID = 450 K | 選択したオーディエンスのID数に対する重複IDの割合（A2） <br>重複% = （B / A） x 100 = （450K / 650K） x 100 = 69.23% <br>重複パーセント = 69.23% | 一致キーごとの重複ID <br> ハッシュ化された電子メールによる重複= 300K <br> Liveramp Idによる重複= 150K | 重複するIDの合計に対する一致キーの重複の割合<br> ハッシュメールの一致キー% = （300K / 450K） x 100 = 66.67% <br> Liveramp Id = （150K / 450K） x 100 = 33.33% |
