# よくある質問

{{limited-availability-release-note}}

このドキュメントでは、Adobe Real-Time CDP Collaborationに関するよくある質問に対する回答を提供します。 Adobe Experience Manager Sitesを導入した直後の企業であっても、特定の機能について明確に説明する必要がある場合でも、必要な情報をここで見つけることができます。

## 権限がなく、製品にアクセスできません

Real-Time CDP Collaborationにアクセスしようとすると、この画面が表示されます。 製品を使用するために必要な権限を取得するにはどうすればよいですか？

Real-Time CDP Collaborationへのアクセス時に![&#x200B; アクセス許可が使用不可の画面](/help/assets/reference/common-questions/permissions-missing-screen.png)

+++選択して回答を表示します

エンドユーザーの場合は、組織のシステム管理者または製品管理者に連絡する必要があります。

システム管理者または製品管理者の場合は、権限ガイドを参照して、自分や他のユーザーにCollaborationを使用するための正しい権限を付与する方法を理解してください。 詳しくは、[&#x200B; アクセス制御の概要](/help/guide/permissions/overview.md)を参照してください。
