# Real-Time CDP Collaboration [!DNL Starter]でのクレジット使用状況と利用状況

このドキュメントでは、招待ユーザーとしてAdobe Real-Time CDP Collaboration [!DNL Starter]に参加する際のクレジットの使用方法について詳しく説明します。 クレジット使用の担当者、アクセスと管理に関する重要な考慮事項について詳しくは、こちらを参照してください。

Collaboration [!DNL Starter]の概要については、[Real-Time CDP Collaboration [!DNL Starter] overview](../overview/starter-overview.md)を参照してください。

## クレジット使用の仕組み {#credit-usage}

招待に同意すると、アクティビティのすべてのクレジット使用状況は、招待した組織によってカバーされます。 クレジットは常に招待者のアカウントから消費され、自分のアカウントは課金されません。

## アクセスと期待値の管理 {#manage-access-and-expectations}

Collaborationでは、**not**&#x200B;がクレジットの使用状況または利用可能状況を自動的に適用しません。 インタラクションがあります。

* 招待ユーザーは、クレジットの使用について話し合うために招待した組織またはパートナーと直接調整する必要があります。
* 招待組織には、次の決定を行う責任があります。
  * Collaborationの機能にアクセスして
  * クレジット消費に関する制限、制限、ガバナンス

>[!IMPORTANT]
>
> Adobeは、組織間の信用共有を管理または調停しません。 すべての使用上の期待は、お客様と招待パートナーの間で直接合意する必要があります。

組織間でのクレジットの割り当て方法について詳しくは、[接続設定ガイド ](../connect/establishing-connections.md)の[ クレジット分割設定](../connect/establishing-connections.md#credit-split) セクションを参照してください。

どのアクティビティがクレジットを消費するか、クレジットの使用状況を追跡または管理する方法について詳しくは、[ クレジットの使用状況を追跡](./my-activity.md)を参照してください。
