# Advertising基盤の概要

{{limited-availability-release-note}}

Advertisingは、高度なツールやテクノロジーを活用して、広告主のマーケティング能力を向上させるサードパーティサービスです。 Real-Time CDP Collaborationなら、広告主は広告プラットフォームと連携してデータの影響力を拡大し、オーディエンスのパフォーマンスに関するより深いインサイトを得ることができます。 詳しくは、[&#x200B; コラボレーションパターン &#x200B;](/help/guide/overview/collaboration-patterns.md) ガイドの広告主向け広告プラットフォームの節を参照してください。

## 利用可能な広告プラットフォーム {#available-advertising-platforms}

現在、Real-Time CDP Collaborationで利用可能な広告プラットフォームは[!DNL Amazon Marketing Cloud] （AMC）のみです。 次のガイドでは、[!DNL AMC]との接続と共同作業について詳しく説明しています。

* [&#x200B; [!DNL Amazon Marketing Cloud]と接続](/help/guide/connect/advertising-platforms/amc.md)
* [&#x200B; [!DNL Amazon Marketing Cloud]さんと共同作業](/help/guide/collaborate/advertising-platforms/amc.md)
