# Collaborationのユースケース

{{limited-availability-release-note}}

Adobe Real-Time CDP Collaborationは、広告主やパブリッシャーとのコラボレーションを可能にし、オーディエンスの発見、活性化、測定の新たな機会を提供します。 これらの連携は、プライバシーとセキュリティを維持しながら、共有データを活用することで、マーケティング戦略を強化します。

Collaborationには、他の共同作業者との連携における3つの主要なユースケースが用意されています。Discover、Activate、Measureです。 ユースケースごとに独自の利点と機能を提供し、マーケティング活動を強化できます。 これらのユースケースは、共同作業者と共にキャンペーンを開始するプロジェクト ](../collaborate/manage-projects.md#project-use-cases)を作成するときに[選択され、そのプロジェクトで使用できる機能を決定します。

## 最新情報 {#discover}

![ オーディエンスインサイトダッシュボードモジュールを見つける。](/help/assets/use-cases/discover.png)

プロジェクト内の&#x200B;**[!UICONTROL オーディエンスインサイト]** ダッシュボードを活用して、キャンペーンのターゲットオーディエンスを発見します。 Insightを使用して、オーディエンスと共同作業者の重複IDの割合と数を把握します。 これにより、キャンペーンの潜在的な新しいオーディエンスを特定できます。 Discover ユースケースの機能について詳しくは、[discover](../collaborate/discover.md) ガイドを参照してください。

## アクティブ化 {#activate}

![ オーディエンスダッシュボードモジュールをアクティブ化します。](/help/assets/use-cases/activate.png)

共同作業者は、キャンペーンで使用するセルフサービスの[宛先](/help/guide/destinations/experience-platform.md)またはクラウドデータウェアハウス（[!DNL Amazon S3]または[!DNL Snowflake]など）を使用して、Experience Platformにオーディエンスをアクティブ化できます。 オーディエンスのアクティベーションについて詳しくは、[activate](../collaborate/activate.md) ガイドを参照してください。

>[!NOTE]
>
> クラウドデータウェアハウスの宛先を設定するには、Adobe担当者にお問い合わせください。

## 測定 {#measure}

web インプレッションなど、さまざまなソースからの既知の顧客エンゲージメントを組み合わせて調査できます。 カスタマイズ可能な簡素化されたレポートで、キャンペーンのパフォーマンスを確認できます。
